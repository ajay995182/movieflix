From empty WordPress to a working site

You need WordPress 6.0+ and PHP 7.4+. Do the steps in this order.

  1. Upload the pluginPlugins, Add New, Upload Plugin, choose movieflix-core-1.5.0.zip, Install, Activate. Activation creates the tables and front-end pages.
  2. Upload the themeAppearance, Themes, Add New, Upload Theme, choose movieflix-theme-2.0.4.zip, Install, Activate.
  3. Fix permalinksSettings, Permalinks, select Post name, Save Changes. Required for the /watch/ links.
  4. Import demo contentOpen MovieFlix in the admin menu and click Import demo content. This is test data only.
  5. Check the settingsMovieFlix, Settings. Later add a Google Client ID and Secret, and switch on profiles, Kids mode and force login.
  6. Open the siteCheck the hero and rows. On a phone, check the bottom navigation and two-column grids.

Demo data, for testing only

  • 38 movies, 8 series, 30 people and 12 channels, using real Indian film titles so the layout looks like a real catalog.
  • Posters come from TMDB. The plugin also ships 13 SVG placeholder posters as fallbacks.
  • Every title plays the same open sample videos (Blender open movies and a public Mux HLS stream). No copyrighted film is included.
  • Use Remove demo in admin before real use.

Going live

  1. Remove the demo content.
  2. Add titles with video you have the rights to.
  3. Add your own artwork.
  4. Set up Google OAuth for real login.
  5. Switch to HTTPS (needed for Google login, notifications and PWA).
  6. Test login and one full watch again.
