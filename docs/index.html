1 Overview — what is MovieFlix?

MovieFlix is a Netflix-style movie & TV streaming website built on WordPress. It is made of two parts. Both must be installed and active:

Plugin

MovieFlix Core

The engine. Stores movies, series, users, My List, watch progress, ratings, Live TV data, admin tools, Google login, notifications, analytics. Creates database tables and front-end pages on activation.

Theme

MovieFlix Theme

The look and pages. Home, browse grids, detail pages, video player UI, Live TV screen, login/register, mobile bottom menu, search, notifications panel, PWA.

Built by me, with AI tools: both the MovieFlix Core plugin and the MovieFlix theme are custom code that I designed with AI tools. They are not third-party plugins or a downloaded theme. The only outside script is hls.js (loaded from jsDelivr) for HLS video.
Important: If the plugin is not active, the theme only shows a message to activate MovieFlix Core. The streaming UI will not load without the plugin.

2 Demo data (for testing only)

Please read: The demo content exists only to test the website. This is not a real streaming service and it does not stream the films named in the demo. No copyrighted video is included.

What the demo import adds:

  • 38 movies, 8 series and 30 cast / director entries. Many use real Indian film titles and real people's names (Telugu, Hindi, Tamil, Kannada) so the layout looks like a real catalog.
  • Poster and backdrop images loaded from TMDB (image.tmdb.org) for those titles. The plugin also ships 13 simple placeholder posters (SVG) used as fallbacks.
  • Sample videos that are the same few open test files on every title: Blender open movies such as Big Buck Bunny and Elephants Dream from a public sample bucket, and a public Mux HLS test stream. They are not the actual films.
  • 12 Live TV channels and a sample subtitle file

After testing, use Remove demo in admin, then add your own licensed titles, artwork and real video or stream URLs before going live.

4 How the plugin and theme were made

Design model: engine + skin. The plugin never draws the Netflix UI by itself; the theme never stores My List or progress by itself. They talk through PHP helpers, post meta, and AJAX. 

WordPress site
│
├── Plugin: MovieFlix Core          ← data + rules + APIs
│     • Custom post types (movie, series, episode, person, channel)
│     • Taxonomies (genre, language, country, rating, quality, year)
│     • Custom DB tables (watchlist, history, ratings, views, activity)
│     • AJAX endpoints (list, rate, progress, search, notify)
│     • Admin screens (settings, import, analytics, upload)
│
└── Theme: MovieFlix                ← pages + CSS + player UI
      • Templates (home, browse, watch, live, login, profile…)
      • style.css (desktop layout + mobile bottom nav + 2-col grids)
      • app.js / player.js / channel-player.js / sw.js
      • Calls plugin helpers & AJAX

Main design choices

1. Custom post types

Movies are not normal blog posts. Each title is a CPT with its own fields (video, poster, runtime, cast…).

2. Custom tables

My List, watch progress, ratings, and activity use dedicated tables so queries stay fast and clear.

3. AJAX actions

Adding to list, rating, saving progress, and search suggestions update the page without a full reload.

4. One class per job

Example: MF_Ajax only handles AJAX; MF_Content only registers post types; MF_Demo only imports sample data.

What happens when you activate the plugin

  1. Creates database tables (watchlist, history, ratings, views, activity)
  2. Registers movie / series / episode / person types and taxonomies
  3. Creates pages: Login, Register, Profile, My List, Continue Watching, Search, Live TV, TV Shows, New & Popular, Genres, Profiles, Lost / Reset Password. (The Watch page is a pretty URL, /watch/title-slug/, not a created page.)
  4. Adds default genre terms
  5. Saves a DB version number for future updates

8 Full setup (install from zero)

Follow these steps in order on a WordPress site (local or hosting).

1 Upload the plugin

  1. WordPress → Plugins → Add New → Upload Plugin
  2. Choose movieflix-core-….zip → Install → Activate
  3. Activation creates tables and pages (Login, My List, Live TV, etc.)

2 Upload the theme

  1. Appearance → Themes → Add New → Upload Theme
  2. Choose movieflix-theme-….zip → Install → Activate
  3. If plugin is off, you only see “please activate Core”

3 Permalinks (required)

  1. Settings → Permalinks
  2. Select Post name
  3. Click Save Changes once

4 Import demo data (testing only)

  1. Open MovieFlix admin → demo / import
  2. Click Import demo content and wait
  3. This loads fake sample data for testing — not a licensed library

5 Settings check

  1. Open MovieFlix → Settings
  2. Optional later: Google Client ID & Secret, profiles, kids mode, force login

6 Open the site

  1. Visit the homepage — hero + rows of demo titles
  2. Check phone: bottom nav + 2-column Movies/Live grids

9 Testing: login & full workflow

After setup + demo import, run this on desktop and mobile.

A Home & browse

  • Homepage shows hero and rows with posters
  • Movies / TV / Live grids load
  • On phone: 2 cards per row, site bottom nav works

B Search

  • Type a title — suggestions with poster appear
  • Open a result → detail page works

C Register & login workflow

  1. Open Sign up — confirm Continue with Google is visible
  2. Create account with email + password
  3. Log out
  4. Open Login — Google button must show here too
  5. Log in again
  6. Optional: Forgot password form loads

Note: Google button always shows. Real Google sign-in needs Client ID + Secret in Settings and Google Cloud Console.

D My List & Continue Watching

  1. While logged in, add a title to My List
  2. Open My List page — title appears
  3. Play a demo title (sample video starts)
  4. Leave mid-way → check Continue Watching

E Live TV & notifications

  • Live page: channel grid + chips
  • Bell icon: panel not cut off; Enable notifications may ask browser permission

F Admin

  • Edit a movie — video / poster fields present
  • Analytics page loads without error

10 After testing → go live

  1. Remove demo content
  2. Add your own movies / series with real video or HLS URLs
  3. Configure Google OAuth if you want real Google login
  4. Use HTTPS (needed for Google, push notifications, PWA install)
  5. Optional: enable profiles, kids mode, membership
  6. Test login + one full watch again on production
